**Honest release and publication claims**

The current release is best described as a **Bengali-Loop-calibrated diarization pipeline using base Nemotron weights**, with experimental fine-tuned comparators. It is not presently a demonstrated improvement from Bengali fine-tuning. A paper can make a useful empirical and methodological contribution about evaluation conventions and adaptation claims, provided it keeps the exploratory status visible and does not claim to have invented gap merging or disproved fine-tuning generally.

**Usable model-card language for the current incumbent**

> This project, by Emrul Zawad, packages NVIDIA Nemotron-3-Diarization with WeSpeaker embeddings and cross-window clustering for long-form Bengali audio. The default uses the original Nemotron checkpoint; it does not contain Bengali-Loop weight updates. Decoder and clustering settings were calibrated using ten labelled Bengali-Loop recordings that were repeatedly inspected during development. Thus “zero-shot” in our experiments refers only to absence of task-specific weight updates, not to a completely untuned pipeline or an unseen language.
>
> In an exploratory second-stage recording-level cross-validation analysis on those ten development recordings, the calibrated base-weight pipeline obtained 26.97% pooled DER and the tested fine-tuned pipeline obtained 27.69%, using our whole-recording scorer, collar zero and the supplied reference policy. The observed difference was +0.72 percentage points for fine-tuning. This analysis did not demonstrate an incremental benefit from the tested adaptation recipe. The recordings and design had already informed earlier experiments, so these values are development results, not an untouched final test estimate.
>
> The default uses 20-second owned cores with context, exclusive speaker output, and same-speaker gap filling up to five seconds. These conventions target pause-inclusive benchmark turns. They may assign a speaker through an acoustic pause and cannot represent simultaneous speakers. Speaker clustering can produce more than eight identities across a recording, but accurate recovery of every speaker is not established; fragmentation and excess identities remain substantial development-set errors. The overall pipeline uses recording-level clustering and is not validated as a causal streaming service.

The card should then list the exact base revision `f667ed73aee57d40cc39428eb768b4fd87a0a29e`, WeSpeaker revision `837717ddb9ff5507820346191109dc79c958d614`, code/config hashes, environment, input conventions, and the final settings `s20_avg_g5_a0.40_c0.60`. Pinning matters because current upstream cards or weights can change. The existing final reference points to base weights (`runs/final/model_reference.json`); an eight-recording refit checkpoint is not an all-ten model. If a new all-ten FT model is eventually trained, give it separate provenance and do not attach the earlier OOF score as its own measured final-model performance.

The evaluation section should preserve the exposure chronology, fold map, data exclusions, training horizon, selected timing shifts, candidate families, scorer version, overlap policy, and uncertainty limitations. The historical phase-3b interval [−2.48,+4.17] pp can be shown as a **conditional recording-bootstrap descriptive interval**, not as a valid post-selection equivalence test. A more concise public card can link the full audit instead of burying these facts in small print. Reference timestamp granularity, pause inclusion, training-span removal and possible reference defects belong in the data limitations.

Include the upstream pretraining caveat: the pinned card names Bengali-containing DISPLACE data; the available evidence does not establish Bengali-Loop source-level exclusion from every upstream media corpus. No new inference about overlap should be invented. Release component terms separately: original code may be MIT; base-model and embedding notices remain applicable. See [03-external-data-and-licences.md](03-external-data-and-licences.md). Attribution should distinguish the project author from upstream model/data creators.

Runtime claims must specify the measured hardware, two evaluated example files, warm/cold/cache conditions and whether embedding/clustering/serialization were included. The approximately 0.013–0.016 end-to-end RTF values in `docs/phase3b_results.md:152–157` are demonstrations, not a broad runtime distribution or proof that every recording fits ≤20 GB. An operational smoke run on unlabelled `test_029` establishes successful execution, output structure and measured speed, not diarization accuracy. Avoid “real time streaming” merely because the backbone is a streaming model.

Floor snapping is **not** part of the frozen phase-3b incumbent. If later released, expose it as an explicit benchmark-convention adapter, retain the native boundaries, and state that its present 24.91% result comes from a post-hoc exploratory look on the same ten recordings. Do not silently replace 26.97% with 24.91% in a card describing the earlier frozen system.

**Can the convention-learning result be a publishable contribution?**

Potentially yes, as an evidence-backed evaluation finding. A compelling result is that an apparently large adaptation gain collapses when a cheap, explicitly matched reference-convention adapter is applied to the baseline, and that activity versus identity errors explain the change. It warns against attributing benchmark improvements to language-specific representation learning without testing simpler alternatives. Such findings can matter even when the best submitted artifact remains an existing checkpoint with better decoding.

Novelty must be narrowly stated. Team Villagers already reports unsuccessful diarization retraining and a same-speaker merge rule with a 3.79-second threshold, plus other temporal filters, in [its Bengali system paper](https://arxiv.org/html/2602.23070v1), section IV and Algorithm 1. Its broad claims and table details are not an independent controlled proof of our mechanism. Cite it as prior art; do not claim the first use of pause merging, the first negative fine-tuning observation, or the first Bengali post-processing improvement. The [CUET paper](https://arxiv.org/html/2602.21741v1) provides a contrasting adaptation result, but our experiments do not identify how much of that other system's gain came from its label convention.

A suitable working title is **“Annotation conventions change apparent adaptation gains in long-form Bengali diarization.”** Avoid a title asserting that fine-tuning is unnecessary for a language. The contribution could consist of a transparent failed original hypothesis, matched decoder controls, an error and annotation audit, and a reproducible procedure for separating benchmark alignment from acoustic diarization quality. A strong paper needs the actual controlled evidence, not just a plausible explanation in its discussion.

The remaining evidence needed, in priority order, is:

1. **A blinded reference-policy intervention.** On independent audio if possible, have humans annotate native acoustic activity/speaker identity and a separately specified turn-ownership policy. Evaluate the same frozen predictions under both. If only the original ten can be reannotated, explicitly call this a within-development mechanism study. Apply any synthetic integer/pause transformations separately; a synthetic transformation proves sensitivity to that transformation, not how the original annotators worked.
2. **A factorial decoder control.** Use fixed tracks/weights where possible and compare base/FT × gap 0/5 × native/floor under the same conventions. Separately show each arm's calibrated practical system. The common-decoder contrast controls decoder choice; the separately calibrated contrast answers which deliverable performs better. Do not select the headline reference policy after reading this table.
3. **Independent evaluation and replication.** One frozen base/FT comparison on new labels gives the strongest practical evidence. Multiple predeclared training seeds assess recipe variability, but do not turn ten recordings into thirty independent test recordings. A second model family, only if readily available within budget, tests whether the finding extends beyond Nemotron; it is helpful rather than a prerequisite for a narrowly framed case study.
4. **Error attribution that preserves its denominator.** Report MISS/FA/CONF seconds and DER, speaker-count error, rare-speaker retention, and fixed-support identity comparisons. Describe oracle identity substitution as an intervention on existing tracks, not a realizable model or a universal minimum. Boundary examples should be selected by a stated sampling rule and annotated without seeing the favored output.

The current automatic detectors provide converging clues about activity mismatch but not a gold standard for acoustic speech. Their shared failure modes, calibration, music sensitivity and latency can explain part of the observed silence/boundary pattern. “Annotators floor both ends” needs direct annotation-policy confirmation or an unbiased human boundary study; whole-second text formatting alone leaves floor, round and coarse human placement all possible. Current median offsets are small relative to the one-second quantization and differ across recordings. Do not present a discovered integer adapter as recovery of the true acoustic boundary.

With only the current ten-recording evidence, an honest technical report or focused workshop case study is plausible; acceptance at any venue cannot be inferred. The contribution is presently an exploratory audit, not a confirmed universal phenomenon or a new state-of-the-art diarizer. Independent replication, a blinded dual-policy reference set, and public artifacts would substantially strengthen it. Reproducibility is constrained if the core repository remains private: a paper should say what is public and provide at least executable evaluation/configuration artifacts and permitted prediction/manifests where possible. The existing preference for a private core is an owner decision, not a reason to imply that independent reproduction is already public.

**Suggested abstract result paragraph, valid now**

> We study a constrained Nemotron adaptation recipe on ten long-form Bengali-Loop recordings. An initial recording-level comparison with restricted decoding showed a large apparent fine-tuning advantage. Subsequent convention-aware baseline controls and symmetric decoder calibration changed the comparison: the base and fine-tuned systems obtained 26.97% and 27.69% pooled DER, respectively, in an exploratory second-stage analysis. We therefore find no demonstrated incremental benefit of this recipe over the calibrated base pipeline on the examined corpus. Diagnostic interventions suggest that pause-inclusive reference conventions explain a substantial part of the original difference, while global speaker assignment remains a major source of error. Because system design repeatedly used the same recordings, these results motivate a frozen independent evaluation rather than a final generalization claim.

Do not add an independent-test sentence until it has an actual source, scorer, partition, freeze date and measured result. A publishable negative finding is not rescued by relabelling development data as test data; its strength comes from clear scope, credible controls and complete reporting.
